# Interactive Traction Inverter Topology & Modulation Workbench

An advanced educational and analytical workbench for EV traction inverters, demonstrating circuit topologies, PWM modulation, dynamic conduction schematics, and multi-channel real-time waveforms.

## GitHub Pages Deployment

This repository is configured to automatically build and deploy to **GitHub Pages** via **GitHub Actions** on every push to `main` or `master`.

### One-Time Setup in GitHub:
1. Push this repository to your GitHub account.
2. Go to **Settings** > **Pages** in your repository.
3. Under **Build and deployment** > **Source**, select **GitHub Actions**.
4. The workflow in `.github/workflows/deploy.yml` will automatically build the project and publish it to GitHub Pages.
